```

│   ├── visual-creation/         # 视觉创作
│   ├── content-processing/      # 内容处理
│   ├── web-scraping/            # 网页抓取
│   ├── social-publish/          # 社交发布
│   └── dev-tools/               # 开发工具

├── architecture-design/         # 架构设计
├── ai-productivity/             # AI 效率
└── dev-tools/                   # 开发工具
```
